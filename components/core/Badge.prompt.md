Status badge / tag — rounded pill for portal case stages, payment states, and inline labels.

```jsx
<Badge tone="success" dot>Settled</Badge>
<Badge tone="info" dot>In Negotiation</Badge>
<Badge tone="warning" dot>Awaiting Docs</Badge>
<Badge tone="blue">MCA</Badge>
```

Tones: `info`/`blue` (blue), `success`/`green` (green), `warning` (amber), `danger` (red), `neutral` (gray). Set `dot` for a status dot.
