Section overline — the small uppercase label above headings ("Why Choose DebtResolvePro", "Our Services", "Our Process"). Pairs with a big display heading below it.

```jsx
<Eyebrow tick>Why Choose DebtResolvePro</Eyebrow>
<h2>Comprehensive Debt Resolution Services</h2>
```

`tone`: blue (default), green, or navy. Set `tick` for a leading green→blue arc accent.
