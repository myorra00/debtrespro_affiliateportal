Dropdown — native `<select>` styled to match Input. For amount ranges, debt type, state, etc.

```jsx
<Select label="Approx. MCA balance">
  <option>Select a range…</option>
  <option>$25k – $100k</option>
  <option>$100k – $250k</option>
  <option>$250k+</option>
</Select>
```

First option is usually a muted placeholder. Spreads native select props.
