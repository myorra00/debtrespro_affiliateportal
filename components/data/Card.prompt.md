Content card — white, rounded, soft shadow. The default surface for portal panels and grouped content.

```jsx
<Card title="Your case" subtitle="Ridgeline Logistics LLC">
  …
</Card>
<Card hover padded={false}><table>…</table></Card>
```

Set `padded={false}` for flush tables; `hover` to lift. For marketing service tiles use `FeatureCard`.
